# Frontend Engineer Portfolio

Personal portfolio built with Vue 3, TypeScript, and Vite. The interface supports Japanese, English, and Simplified Chinese.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Source structure

- `src/components/SiteHeader.vue` — site navigation, language selection, and theme control
- `src/components/IntroductionSection.vue` — introductory hero section
- `src/components/ExperienceSection.vue` — career timeline
- `src/components/ProjectSection.vue` — selected projects
- `src/components/ExpertiseSection.vue` — areas of expertise
- `src/components/ContactSection.vue` — contact callout
- `src/components/SiteFooter.vue` — site footer
- `src/i18n.ts` — typed interface copy for supported languages
